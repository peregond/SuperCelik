# Super Čelik для Linux (бета)

Версия для Linux в **бета-статусе**: в окне приложения это помечено, во вкладке «О программе» есть ссылка на [GitHub Issues](https://github.com/peregond/SuperCelik/issues/new) для сообщений об ошибках и отзывов.

Avalonia (.NET 8). Протокол карты, проверка подписи (CMS + цепочка до сертификатов МУП), подпись файла и тексты общие с Windows-версией:
файлы `windows/SerbiaID.Windows/{Card,CardErrors,Crypto,Models,Loc,SerbianScript,SelfTest}.cs` подключены ссылками. Своё здесь только:
доступ к PC/SC через `libpcsclite` (`Native.cs`), интерфейс и макет печатного листа (`PrintSheet.cs`, PDF через SkiaSharp).

## Что нужно в системе
- **С `.deb` вручную ставить ничего не нужно**: пакет зависит от `pcscd` (служба смарт-карт), `libccid` (драйвер USB-ридеров) и `libnss3-tools`, `apt` поставит их сам, а после установки запускает службу (`pcscd.socket`). Если приложение всё же пишет «Служба смарт-карт не запущена»: `sudo systemctl enable --now pcscd.socket`.
- С **.tar.gz** (или не на Debian) `pcscd`, `libpcsclite1` и `libccid` (в других системах `pcsc-lite`, `ccid`) нужно поставить самому, и `libnss3-tools`, если хотите настройку браузера из раздела ниже.
- USB-ридер смарт-карт (класса CCID: почти все).
- Для открытия PDF / страницы релиза: `xdg-utils` (необязательно).

## Вход в браузере (eUprava и другие порталы)
В сборках (кроме Flatpak) в папке `pkcs11` лежит модуль PKCS#11 [srb-id-pkcs11](https://github.com/ubavic/srb-id-pkcs11) (общественное достояние). При первом запуске приложение предлагает подключить его к Firefox, Chrome, Edge и Chromium, и то же делает кнопка «Настроить вход в браузере» на вкладке «Токен» (она запускает `modutil` из `libnss3-tools`; без вашего согласия ничего не меняется). После этого браузер нужно полностью закрыть и открыть снова.
- Если браузер при входе не предлагает карту, полностью закройте его (все окна), откройте страницу заново и, если нужно, выньте карту из ридера и вставьте снова. Кнопка «Проверить вход в браузере» рядом с «Войти на eUprava» показывает в карточке «Сертификаты», что не так: видит ли программа ридер и карту, есть ли модуль в браузерах и запускается ли он, и видит ли карту сам модуль (она спрашивает NSS, библиотеку браузеров, через `modutil -list`), и подсказывает, что делать дальше.
- **Профили Firefox** ищутся в `~/.mozilla/firefox` и в `$XDG_CONFIG_HOME/mozilla/firefox` (`~/.config/mozilla/firefox`: там Firefox 147 и новее держит новые профили), а также все профили, которые `profiles.ini` указывает в других местах.
- **Chrome, Chromium, Edge и Brave** используют одну общую базу NSS, поэтому одной регистрации хватает им всем. Это `~/.pki/nssdb`; Chromium 146 и новее (Edge идёт за ним) используют `~/.local/share/pki/nssdb`, если старой базы нет. Приложение подключает модуль к каждой существующей копии, а если их нет и один из этих браузеров установлен, создаёт `~/.pki/nssdb`: её подхватывают все версии.
- Когда вы один раз согласились, приложение само подключает модуль заново (при запуске и по кнопке «Войти на eUprava»), если у нового профиля или нового браузера его ещё нет, и сообщает только о том, что подключило.
- Модулю нужна служба смарт-карт: пока `pcscd` остановлен, NSS отказывается его добавить (`CKR_FUNCTION_FAILED`). Приложение скажет об этом: `sudo systemctl enable --now pcscd.socket`, затем нажмите кнопку снова.
- Модуль собирается из исходников автора в нашем CI под **glibc 2.28 и новее** (Ubuntu 20.04 и новее, Debian 10 и новее, Linux Mint 20 и новее, RHEL 8 и новее). В более старой системе приложение скажет, что NSS не может его загрузить; там используйте OpenSC. Ещё нужна библиотека `libpcsclite1`, её ставит .deb.
- Браузеры из **Snap** или **Flatpak** (Firefox и Chromium в Ubuntu; Chrome, Edge и Brave из Flathub) работают в изолированной среде, которая не пускает к ним модуль, поэтому приложение их не трогает и говорит об этом. Ubuntu описывает ручную настройку для Snap-браузеров ([Enable smart cards in snapped browsers](https://documentation.ubuntu.com/desktop/en/latest/how-to/enable-smart-cards-in-snapped-browsers)), но называет её экспериментальной; надёжный путь это обычный пакет: Firefox из [репозитория Mozilla](https://support.mozilla.org/kb/install-firefox-linux), Chrome или Edge с их сайтов.
- В сборках для **arm64** модуль тоже есть (собирается так же).

## Чего нет по сравнению с Windows
- Печать: «Печать» сохраняет PDF во временный файл и открывает его в просмотрщике (там окно печати), «Сохранить PDF» кладёт файл куда выберете.

## Обновления
Приложение проверяет новую версию и обновляется само. С `.deb` оно скачивает новый `.deb` и ставит его через `pkexec apt-get install` (система спросит пароль администратора); с `.tar.gz` в папке, куда можно писать, скачивает **только изменившиеся файлы** (в релизе есть `.manifest.json` с SHA-256 каждого файла и `.zip`, из которого приложение читает отдельные записи запросами диапазонов HTTP; каждый файл проверяется по манифесту, а манифест по контрольной сумме GitHub) и заменяет их на месте, а при неудаче скачивает весь `.tar.gz`. `.deb` всегда ставится целиком, потому что dpkg должен знать файлы. Пакет ставится, только если его SHA-256 совпадает с контрольной суммой, которую GitHub показывает для файла релиза; иначе приложение просто открывает страницу релиза. После обновления приложение перезапускается.

## Запуск и проверка
    dotnet run --project linux/SerbiaID.Linux -- --demo [вкладка 0-3] [--dark] [--state noreader|nocard|busy|error]
    dotnet run --project linux/SerbiaID.Linux -- --demo --shot out.png      # окно как PNG (вымышленные данные)
    dotnet run --project linux/SerbiaID.Linux -- --demo --pdf out.pdf       # печатный лист как PDF
    SuperCelik --selftest                                                  # отчёт по реальной карте без личных данных (selftest.txt рядом с программой, а если папка установки только для чтения, то в текущей папке; путь можно задать: `--selftest report.txt`)

Настройки: `~/.config/SuperCelik/settings.json`. «Показать демо-данные» на вкладке «Настройки» заполняет окно вымышленными данными (карта не нужна), а при выключении возвращает настоящий ридер. Язык интерфейса берётся из `LANG` (ru / sr / en), меняется на вкладке «Настройки».

**Статус:** на реальной карте под Linux не проверялось (разработка велась на Mac: интерфейс, PDF и сборка проверены, чтение карты через `libpcsclite` и CMS-подпись на Linux — нет). Первым делом запустите `--selftest`.

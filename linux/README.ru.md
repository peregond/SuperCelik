# Super Čelik для Linux (бета)

Версия для Linux в **бета-статусе**: в окне приложения это помечено, во вкладке «О программе» есть ссылка на [GitHub Issues](https://github.com/peregond/SuperCelik/issues/new) для сообщений об ошибках и отзывов.

Avalonia (.NET 8). Протокол карты, проверка подписи (CMS + цепочка до сертификатов МУП), подпись файла и тексты общие с Windows-версией:
файлы `windows/SerbiaID.Windows/{Card,CardErrors,Crypto,Models,Loc,SerbianScript,SelfTest}.cs` подключены ссылками. Своё здесь только:
доступ к PC/SC через `libpcsclite` (`Native.cs`), интерфейс и макет печатного листа (`PrintSheet.cs`, PDF через SkiaSharp).

## Что нужно в системе
- **С `.deb` вручную ставить ничего не нужно**: пакет зависит от `pcscd` (служба смарт-карт), `libccid` (драйвер USB-ридеров) и `libnss3-tools`, `apt` поставит их сам, а после установки запускает службу (`pcscd.socket`). Если приложение всё же пишет «Служба смарт-карт не запущена»: `sudo systemctl enable --now pcscd.socket`.
- С **.tar.gz** (или не на Debian) `pcscd`, `libpcsclite1` и `libccid` (в других системах `pcsc-lite`, `ccid`) нужно поставить самому, и `libnss3-tools`, если хотите настройку браузера из раздела ниже.
- USB-ридер смарт-карт (класса CCID: почти все).
- Для открытия PDF / страницы релиза: `xdg-utils` (необязательно).

## Вход в браузере (eUprava и другие порталы)
В сборках для x64 в папке `pkcs11` лежит модуль PKCS#11 [srb-id-pkcs11](https://github.com/ubavic/srb-id-pkcs11) (общественное достояние). При первом запуске приложение предлагает подключить его к Firefox и Chrome / Chromium, и то же делает кнопка «Настроить вход в браузере» на вкладке «Токен» (она запускает `modutil` из `libnss3-tools`; без вашего согласия ничего не меняется). После этого браузер нужно полностью закрыть и открыть снова. В сборках для **arm64** модуля нет (автор не выпускает сборку для arm64): подключите OpenSC или соберите srb-id-pkcs11 сами и добавьте в браузер вручную. Браузеры из Snap и Flatpak автоматически не настраиваются.

## Чего нет по сравнению с Windows
- Печать: «Печать» сохраняет PDF во временный файл и открывает его в просмотрщике (там окно печати), «Сохранить PDF» кладёт файл куда выберете.

## Обновления
Приложение проверяет новую версию и обновляется само. С `.deb` оно скачивает новый `.deb` и ставит его через `pkexec apt-get install` (система спросит пароль администратора); с `.tar.gz` в папке, куда можно писать, скачивает **только изменившиеся файлы** (в релизе есть `.manifest.json` с SHA-256 каждого файла и `.zip`, из которого приложение читает отдельные записи запросами диапазонов HTTP; каждый файл проверяется по манифесту, а манифест по контрольной сумме GitHub) и заменяет их на месте, а при неудаче скачивает весь `.tar.gz`. `.deb` всегда ставится целиком, потому что dpkg должен знать файлы. Пакет ставится, только если его SHA-256 совпадает с контрольной суммой, которую GitHub показывает для файла релиза; иначе приложение просто открывает страницу релиза. После обновления приложение перезапускается.

## Запуск и проверка
    dotnet run --project linux/SerbiaID.Linux -- --demo [вкладка 0-3] [--dark] [--state noreader|nocard|busy|error]
    dotnet run --project linux/SerbiaID.Linux -- --demo --shot out.png      # окно как PNG (вымышленные данные)
    dotnet run --project linux/SerbiaID.Linux -- --demo --pdf out.pdf       # печатный лист как PDF
    SuperCelik --selftest                                                  # отчёт по реальной карте без личных данных (selftest.txt рядом с программой, а если папка установки только для чтения, то в текущей папке; путь можно задать: `--selftest report.txt`)

Настройки: `~/.config/SuperCelik/settings.json`. Язык интерфейса берётся из `LANG` (ru / sr / en), меняется на вкладке «Настройки».

**Статус:** на реальной карте под Linux не проверялось (разработка велась на Mac: интерфейс, PDF и сборка проверены, чтение карты через `libpcsclite` и CMS-подпись на Linux — нет). Первым делом запустите `--selftest`.

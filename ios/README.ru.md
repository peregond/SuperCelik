# Super Čelik для iPhone и iPad

Приложение читает карту через проводной считыватель смарт-карт (USB-C или MFi) и использует тот же код, что и версия для Mac:
протокол карты (`Sources/SerbiaID/EidCard.swift`), проверку подписи МУП, разбор сертификата
токена и печатную форму МУП (`MupPrintLayout.swift`, PDF один в один как на Mac).
Доступно в [App Store](https://apps.apple.com/app/id6835244146).

Приложение следит за считывателем: когда ридер подключён и карта вставлена, оно само начинает чтение (на вкладке «Карта» личные данные, на вкладке «Токен» сертификаты). На экранах «Карта» и «Токен» видно, подключён ли считыватель и вставлена ли карта.

## Токен: PIN, PUK, подпись
На вкладке «Токен» есть «Сменить PIN» и «Разблокировать по PUK». Обе функции **на реальном токене не проверены** (приложение говорит об этом в своём предупреждении); неверный PUK тратит попытку.

На вкладке «Токен» есть и «Подписать файл»: выберите файл, введите PIN, и приложение сделает отсоединённую подпись CMS (`.p7s`, SHA-256), которую вы сохраняете через меню «Поделиться». На вкладке «Карта» можно ещё сохранить фото и экспортировать данные в JSON (через «Поделиться»). Подпись на реальном токене тоже **не проверена**; неверный PIN тратит попытку.

## Вход на eUprava картой
На вкладке «Токен» есть «Войти на eUprava». В iOS приложение не может передать ключ карты в Safari, поэтому внутри лежит **расширение-токен CryptoTokenKit** (`ios/TokenExtension`, драйвер `SuperCelikTokenDriver`, class id `app.supercelik.token`): пока ридер и карта подключены, сама iOS предлагает Safari сертификат карты и спрашивает PIN в системном окне. Приложение открывает `https://euprava.gov.rs/prijava` в полноэкранном окне Safari. Расширению нужна группа связки ключей `$(AppIdentifierPrefix)com.apple.token`. Окно PIN рисует iOS: значок и клавиатуру в нём приложение не контролирует. Проверено на реальном iPhone с настоящей картой. Если драйвер не подключён (например, сразу после переустановки), приложение предупреждает перед открытием страницы.

## Быстрые действия на главном экране
Долгое нажатие на значок: «Прочитать карту», «Распечатать» и «Войти на eUprava» (`QuickActions.swift`).

## Чтение по NFC отключено
Код чтения по NFC (`NFCCardReader.swift`) остался в проекте, но выключен флагом `PhoneModel.nfcEnabled = false`.
Разрешение NFC убрано из `Config/SuperCelik.entitlements` и `Config/Info.plist`; как вернуть, написано в комментарии
в entitlements. По открытым данным у сербских ID-карт чип только контактный, поэтому NFC для них не подходит.

## Поддержка ридеров на устройстве
Проводной считыватель на iPhone/iPad работает, только если iOS показывает этот считыватель приложению (`TKSmartCardSlotManager`). Нужен USB-C iPhone 15 и новее или iPad с CCID-считывателем, либо MFi-считыватель.
Если система считыватель не показывает, приложение остаётся в состоянии «не подключён».
Демо-данные (Настройки → «Показать демо-данные») работают без карты.

## Готовые сборки
CI на каждый PR и на каждый релиз собирает два файла (в Actions: артефакт `SuperCelik-iOS`, в релизе: рядом с dmg):
- `SuperCelik-<версия>-iOS-simulator.zip`: приложение для симулятора iPhone на Mac. Нужен только Xcode (в нём есть Simulator).
  Распакуйте, запустите Simulator, выберите любой iPhone и перетащите `SuperCelik.app` на окно симулятора.
- `SuperCelik-<версия>-iOS-unsigned.ipa`: сборка для iPhone **без подписи**; её нужно подписать своим аккаунтом
  (Sideloadly, AltStore, Apple Configurator или `Xcode → Devices`).

## Публикация в App Store
См. `docs/APPSTORE.md`: запись приложения с bundle id `app.supercelik`, секреты `APPLE_TEAM_ID`, `ASC_KEY_ID`,
`ASC_ISSUER_ID`, `ASC_KEY_P8_BASE64` и workflow «App Store (iOS / iPadOS)».

## Сборка из Xcode
Откройте `ios/SuperCelik.xcodeproj` (папку репозитория нужно скачать целиком: проект берёт общий код из `Sources/SerbiaID`).
Цель SuperCelik → Signing & Capabilities → выберите свою команду (Team). Если bundle id `app.supercelik` занят, поменяйте его.
